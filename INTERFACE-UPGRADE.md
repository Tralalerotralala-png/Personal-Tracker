# Interface upgrade

- Overview is now the default route when no valid tab hash is present.
- Tabs can be dragged on desktop; Settings > Navigation order has Up/Down controls for touch and keyboard users. Order is saved per device.
- Six-day weather icons now have text descriptions underneath.
- Settings > Typography offers Clean (default), Pixel, or Monospace fonts and 14–21px text sizes, saved per device.
- Service worker cache version bumped to v6.

## GitHub update
Upload the extracted files to the same paths in the repository, keeping the existing config.js. Do not upload the outer folder as a nested directory. The ZIP excludes config.js to avoid accidentally replacing your working Supabase configuration.
